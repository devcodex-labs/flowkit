# 编译诊断

这里列出v1.0.0全部52个编译诊断。C053和C059为warning，其余为error；编号不连续，不应把空缺编号当作功能。先看code，再结合file/line/column/nodeId定位。

## 如何复现与复验

每条的错误与修复源码来自同版本独立诊断用例。把需要的源码保存为case.workflow.js，在已安装FlowKit的ESM目录运行compile/check。涉及agent映射的用例先创建skills/writer.md，写入任意合法UTF-8说明；涉及远程URL只做静态检查，不会联网。条目给出的options需传给SDK，CLI支持的对应参数见命令行页。

```js
import { compile } from '@devcodex-labs/flowkit';
const result = await compile('case.workflow.js', { /* 使用条目中的options */ });
console.log(result.diagnostics);
```

修复后应没有该诊断，示例的相邻合法输入应为空诊断。不要在业务项目中直接覆盖现有工作流；在单独目录复现。下方长例可横向滚动和复制。
